One order. Three consumers.Silent intro → Send for sound · RFCs → PRs → chat → review

A lot of code. One clear story.

  1. Two verbose RFCs and three fictional pull requests pile up to 103,271 lines.
  2. An order-paid event wakes inventory, receipts, and shipping.
  3. Follow the consumer calls, a receipt's total, and its retry path in exact code.

The opening plays silently. Press Send on “OK! Sound is on” to start the narrated review, with pointing and words following the voice. Use Skip intro to open the review paused. Click any node or message to inspect it, or choose Manual to pause between beats.

Nearby targets slide automatically, horizontally or vertically. The author only chooses what to explain.

All source and narration were created for this fictional example. Read the showcase source · Explore a longer review.
