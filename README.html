Review Story

Narrated code reviews with synchronized diagrams, source highlights, and pointing.

Working example: fictional stock-summary code. Play audio, or use the arrows to read.

Open review full screen ↗Markdown READMESkill instructions

Use

Select a page or diagram. Click a message to inspect its source. Manual mode pauses after each beat; Space advances. Cursor path shows the current beat's travelled and planned paths.

Install

mkdir -p ~/.codex/skills
ln -s "$PWD/skills/review-story" ~/.codex/skills/review-story

Run from the repo. Then ask: Use $review-story to review these stacked PRs against main.

The example runs offline. New narration uses local speech synthesis; initial setup downloads models. Authoring and build commands.
